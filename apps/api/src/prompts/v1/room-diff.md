# Room condition diff — v1

## 1. Role and task

These are two photographs of the same room, before and after a tenancy.

## 2. Ignore

Lighting, shadows, white balance, exposure, camera angle and distance, and the
presence or absence of furniture and personal belongings.

## 3. Report only

Changes to the fixed condition: walls, floor, ceiling, fittings, fixtures,
doors, windows.

## 4. Output

Respond with only JSON, no other text:

```
